## 1. 跨任务稳定减熵探测规律与模式
- **大资产与构建产物隔离**: UI 前端构建产物 (`ui/dist/`) 需严格登记于 `.gitignore`，避免生产编译打包产物被纳入源码版本追踪导致文件树爆炸。
- **记忆库脱脂防线**: `memory-bank/` 核心文件必须严格守卫 4096 Token 红线，长文本报告或历史部署事故必须归档至 `docs/archive/`。
- **脚本目录收敛规范**: `scripts/` 下的一级子目录必须收敛至 `{ci, dev, deploy, diagnostics, legacy, maintenance, reporting}` 标准结构，杜绝无序蔓延。
- **归档资产索引完整性**: `docs/archive/` 内历史文档必须在资产台账或索引中具备一跳可达的反链，严禁无头孤儿归档。
- **Agent 身份单射合规**: 保持 `memory-bank/agents/<slug>/activeContext.md` 的规范性，杜绝历史冗余非标准目录。
